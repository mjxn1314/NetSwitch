# NetSwitch（IP 快切）

> Windows 下的网络配置快速切换工具，图形化界面。支持 **静态 IP / DHCP 一键切换、单网卡多 IP 绑定、配置档案保存与一键应用、永久 / 临时静态路由管理、IP 段存活扫描**，并提供**免安装 Python 的独立 exe**。

## 功能特性

### IP 切换

- **网卡总览**：快速枚举本机网卡，显示 IP、子网掩码、网关、DNS 以及获取方式（DHCP / 静态）。
- **一键 DHCP**：快速切换为自动获取 IP 地址和 DNS。
- **静态 IP 设置**：可配置主 IP、子网掩码、默认网关、首选 / 备用 DNS。
- **多 IP 绑定**：同一张网卡可绑定多个 IP（附加 IP），各自指定子网掩码，适用于同时访问多个网段；附加 IP 支持鼠标右键在独立窗口中修改。
- **配置档案**：将整套 IP 配置保存为档案，**档案不绑定网卡**，可应用到任意选定的网卡。
- **右键管理**：在档案上点击鼠标右键，可编辑（独立窗口）、一键应用、删除。

### 静态路由管理（v1.4 新增）

- **路由查看**：查看系统 IPv4 路由表，显示目标网络、子网掩码、网关（下一跳）、网卡、度量值、类型。
- **永久 / 临时区分**：自动识别并标记「永久路由」（重启保留）与「临时路由」。
- **网卡筛选**：可按「全部网卡」或指定网卡过滤，并支持「仅显示静态路由」。
- **添加路由**：可指定目标网络、掩码、网关、度量值、出接口，自由选择创建**永久**或**临时**路由。
- **右键编辑**：在路由条目上点击鼠标右键，可在弹出的独立窗口中修改（目标 / 掩码 / 网关 / 度量 / 出接口 / 永久），确定后自动保存（删旧 + 加新）。
- **删除路由**：选中即可删除，永久路由会同时清除持久条目。

### 体验与安全

- **独立 exe**：基于 PyInstaller 打包，单文件、无控制台、启动自动请求管理员权限，**目标电脑无需安装 Python**。
- **配置独立存放**：配置文件保存在系统「文档」目录，不污染程序目录，便于备份。
- **专属图标**：蓝青渐变「切换」图标，同时用于 exe 图标、窗口标题栏与横幅左上角。
- **现代界面**：渐变横幅、卡片式布局、整体可滚动；IP 设置标签与输入框整齐对齐；操作过程无黑框 / 蓝框闪烁。
- **安全可靠**：修改基于系统原生能力，配置立即生效、无需重启网卡；设置失败不会破坏现有配置。

### 存活扫描（v1.7 新增）

- **快速扫描**：扫描指定 IP 段的存活主机，支持 CIDR（如 `192.168.1.0/24`）、起止范围（`192.168.1.10-192.168.1.50` 或 `10-50`）、单 IP 与逗号分隔混合输入。
- **多线程并发**：可自定义线程数与单主机超时时间，大幅加快大网段扫描。
- **双探测方式**：ICMP（ping）与 TCP 端口探测可同时开启，主机任一探测成功即判定存活；TCP 端口支持自定义端口列表。
- **信息丰富**：可选解析反向主机名、获取 MAC 地址，并显示延迟与开放端口。
- **进度可控**：实时进度条与状态提示，支持「停止」随时中断；可勾选「仅显示存活主机」过滤结果。
- **导出 CSV**：扫描结果一键导出为 CSV 文件（UTF-8 BOM，Excel 直接打开不乱码）。

## 使用说明

### 切换为 DHCP

1. 在「网卡选择」中选择要操作的网卡。
2. IP 设置选择「自动获取 IP（DHCP）」。
3. 点击「应用配置」。

### 设置静态 IP

1. 选择目标网卡。
2. 选择「使用下面的静态 IP」。
3. 填写主 IP、子网掩码、网关、DNS（字段横向排列）。
4. 点击「应用配置」。

### 绑定多个 IP

1. 在「附加 IP」区域填写附加 IP 和子网掩码，点击「添加」，可重复添加多个。
2. 点击「应用配置」，主 IP 与所有附加 IP 会一并生效。
3. 附加 IP 不设置默认网关（一张网卡只有一个默认网关，作用于主 IP）。
4. 如需修改，在附加 IP 上点击鼠标右键 →「编辑此附加 IP」，在弹出的独立窗口中修改；也可右键删除。

### 配置档案

- **保存**：填写档案名称，点击「保存/覆盖」。
- **一键应用**：先在上方选择目标网卡，再选中档案，点击「一键应用」；也可直接双击档案。
- **编辑**：在档案上点击鼠标右键 →「编辑档案」，在弹出的独立窗口中修改后确定。
- **删除**：右键 →「删除档案」。

### 管理静态路由

1. 切换到「路由管理」标签页。
2. 上方可按网卡筛选、勾选「仅显示静态路由」，点击「刷新」查看当前路由表。
3. **添加**：在下方表单填写目标网络、掩码、网关（度量值 / 出接口可留空），勾选或取消「永久路由」，点击「添加路由」。
4. **编辑**：在某条路由上点击鼠标右键 →「编辑此路由」，在弹出的独立窗口中修改后确定，系统会自动删旧并加新。
5. **删除**：在路由表中选中一条，点击「删除选中路由」（或右键 →「删除此路由」）。

> 说明：「永久路由」写入系统持久路由表，重启后仍然保留；「临时路由」重启后消失。

### 存活扫描

1. 切换到「存活扫描」标签页。
2. 在「目标范围」中填写要扫描的网段或 IP 列表，例如 `192.168.1.0/24`。
3. 设置线程数与超时（毫秒）；勾选探测方式：ICMP、TCP（可自定义端口，默认 `80,443,22,445,3389,139`）。
4. 按需勾选「解析主机名」「获取 MAC」「仅显示存活主机」。
5. 点击「开始扫描」，可随时「停止」；扫描完成后点击「导出 CSV」保存结果。

> 支持的目标格式示例：`192.168.1.0/24`、`192.168.1.1-192.168.1.100`、`192.168.1.10-50`、`192.168.1.1,192.168.1.5`。
> 提示：部分主机禁用 ICMP（ping 不通）但开放端口，建议同时勾选 TCP 探测，避免漏报。

## 配置文件位置

配置文件统一保存在当前用户的系统「文档」目录下：

```
文档\NetSwitch\ip_profiles.json
```

- 程序首次启动时，若旧版本在程序目录留有 `ip_profiles.json`，会**自动迁移**到新位置。
- 该文件可直接备份或在不同电脑间迁移；配置文件已被 `.gitignore` 忽略，不会上传。

示例结构：

```json
{
  "profiles": [
    {
      "name": "办公网络",
      "mode": "static",
      "ip": "192.168.1.50",
      "mask": "255.255.255.0",
      "gateway": "192.168.1.1",
      "dns1": "114.114.114.114",
      "dns2": "8.8.8.8",
      "extra_ips": [
        { "ip": "10.0.0.5", "mask": "255.255.255.252" }
      ],
      "saved_at": "2026-10-28 10:00"
    }
  ]
}
```

## 实现原理

- 读取网卡信息：CIM / WMI（`Get-NetAdapter`、`Get-NetIPAddress`、`Get-NetRoute` 等）。
- 修改 IP 配置：`netsh interface ip`（`set` / `add address`、`set` / `add dnsservers`）。
- 路由管理：`route.exe`（`route print` / `route add` / `route delete`，永久路由加 `-p`），并结合注册表持久路由表标记类型。
- 图形界面：Python 标准库 `tkinter`，无需第三方 GUI 依赖。
- 子进程统一以 `CREATE_NO_WINDOW` 方式后台运行，避免弹窗闪烁。

## 常见问题

**Q：提示权限不足 / 拒绝访问？**
A：修改 IP 和路由需要管理员权限。exe 与启动器会自动请求提权；命令行方式请以管理员身份运行。

**Q：静态 IP 配置错误导致无法联网？**
A：重新运行 NetSwitch，选择对应网卡并切换为 DHCP，即可恢复网络。

**Q：能不能给虚拟网卡（VMware / VirtualBox）改 IP？**
A：可以，但虚拟机内部的网卡建议在对应虚拟机设置中修改。

**Q：附加 IP 有什么用？**
A：当设备需要同时访问多个不同网段（如同时接入内网业务系统和外网）时，可通过一张网卡绑定多个 IP 实现，无需插拔网线或更换网卡。

**Q：永久路由和临时路由有什么区别？**
A：永久路由写入系统持久路由表，重启后仍然保留；临时路由仅当前运行期间有效，重启后消失。

**Q：扫描时有些主机 ping 不通但实际在线，为什么？**
A：很多系统默认禁止 ICMP 回显（ping）。建议同时勾选「TCP 探测」并保留常用端口（如 80、443、22、445），通过端口连通性判断主机是否存活。

**Q：扫描会不会很慢？**
A：可以调大线程数（默认 100）并适当减小超时值；对 /24 等大网段建议使用 200–500 线程。扫描过程中可随时点击「停止」中断。

**Q：扫描结果能保存吗？**
A：可以。点击「导出 CSV」即可将 IP、状态、主机名、延迟、MAC、开放端口保存为 CSV，Excel 可直接打开。
