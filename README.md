# NetSwitch（IP 快切）

> Windows 下的 IP 地址快速切换工具，图形化界面，支持静态 IP / DHCP 一键切换、单网卡多 IP 绑定、配置档案保存与一键应用。

## 功能特性

- **网卡总览**：快速枚举本机网卡，显示 IP、子网掩码、网关、DNS 以及获取方式（DHCP / 静态）。
- **一键 DHCP**：快速切换为自动获取 IP 地址和 DNS。
- **静态 IP 设置**：可配置主 IP、子网掩码、默认网关、首选 / 备用 DNS。
- **多 IP 绑定**：同一张网卡可绑定多个 IP（附加 IP），各自指定子网掩码，适用于同时访问多个网段。
- **配置档案**：将整套 IP 配置保存为档案，**档案不绑定网卡**，可应用到任意选定的网卡。
- **右键管理**：在档案上点击鼠标右键，可编辑、一键应用、删除。
- **安全可靠**：修改基于系统原生能力，配置立即生效、无需重启网卡；设置失败不会破坏现有配置。

## 运行环境

- Windows 10 / Windows 11（Windows Server 2016 及以上亦可）
- Python 3.8 及以上版本（安装时勾选 **Add Python to PATH**）
- 运行时需要 **管理员权限**

## 快速开始

### 方式一：使用启动器（推荐）

1. 克隆或下载本仓库到本地。
2. 双击 `启动工具.bat`。
3. 在弹出的 UAC（用户账户控制）窗口中点击「是」，即可打开程序。

> 启动器会自动请求管理员权限。若 Python 未加入系统 PATH，请编辑 `启动工具.bat`，将其中的 Python 路径修改为你本机的实际安装路径。

### 方式二：命令行运行

```powershell
# 以管理员身份打开 PowerShell
python ip_address_changer.py
```

## 使用说明

### 切换为 DHCP

1. 在「网卡选择」中选择要操作的网卡。
2. IP 设置选择「自动获取 IP（DHCP）」。
3. 点击「应用配置」。

### 设置静态 IP

1. 选择目标网卡。
2. 选择「使用下面的静态 IP」。
3. 填写主 IP、子网掩码、网关、DNS。
4. 点击「应用配置」。

### 绑定多个 IP

1. 在「附加 IP」区域填写附加 IP 和子网掩码，点击「添加」，可重复添加多个。
2. 点击「应用配置」，主 IP 与所有附加 IP 会一并生效。
3. 附加 IP 不设置默认网关（一张网卡只有一个默认网关，作用于主 IP）。

### 配置档案

- **保存**：填写档案名称，点击「保存/覆盖」。
- **一键应用**：先在上方选择目标网卡，再选中档案，点击「一键应用」；也可直接双击档案。
- **编辑**：在档案上点击鼠标右键 →「编辑档案」，在弹出的独立窗口中修改后确定。
- **删除**：右键 →「删除档案」。

## 配置文件

档案保存在程序同目录的 `ip_profiles.json` 文件中，可随程序一起备份或迁移。示例：

```json
{
  "profiles": [
    {
      "name": "办公网络",
      "mode": "static",
      "ip": "192.168.1.50",
      "mask": "255.255.255.0",
      "gateway": "192.168.1.1",
      "dns1": "114.114.114.114",
      "dns2": "8.8.8.8",
      "extra_ips": [
        { "ip": "10.0.0.5", "mask": "255.255.255.252" }
      ],
      "saved_at": "2026-10-27 23:00"
    }
  ]
}
```

## 实现原理

- 读取网卡信息：WMI / CIM（`Win32_NetworkAdapter`、`Win32_NetworkAdapterConfiguration`）。
- 修改 IP 配置：`netsh interface ip` 命令（`set` / `add address`、`set` / `add dnsservers`）。
- 图形界面：Python 标准库 `tkinter`，无需额外安装第三方依赖。

## 常见问题

**Q：提示权限不足 / 拒绝访问？**
A：修改 IP 需要管理员权限，请使用 `启动工具.bat` 运行，或以管理员身份运行 Python 脚本。

**Q：静态 IP 配置错误导致无法联网？**
A：重新运行 NetSwitch，选择对应网卡并切换为 DHCP，即可恢复网络。

**Q：能不能给虚拟网卡（VMware / VirtualBox）改 IP？**
A：可以，但虚拟机内部的网卡建议在对应虚拟机设置中修改。

**Q：附加 IP 有什么用？**
A：当设备需要同时访问多个不同网段（如同时接入内网业务系统和外网）时，可通过一张网卡绑定多个 IP 实现，无需插拔网线或更换网卡。
